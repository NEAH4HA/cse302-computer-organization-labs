## Labs 10 and 11 follow the design shown in class

Labs 10 and 11 were rebuilt to match the instructor's Logisim design in the lab photos.
- **Lab 10** uses the `Register File` → `Register Cell` → `32 bit Register` hierarchy with the zippers.
- **Lab 11** uses the `32 Bit ALU` made of 32 × `1 bit ALU`.

The circuits use the same circuit names, pins, op codes and block symbols, so they plug into the class CPU the same way.
They were built here with Logisim's API and tested; nothing was copied from the class file. The photos themselves are not published.
Labs 7–9 and Lab 12 are not covered by the photos and were left unchanged.

## How the `.circ` files were made with the real Logisim app

The circuits were **not** typed in as hand-written XML. Each one was built by driving **Logisim 2.7.1's own Java code**
(`build/src/*.java`, compiled against `logisim-generic-2.7.1.jar`). These are the same code paths the GUI uses:

| GUI action | Logisim code used |
|---|---|
| File > New | the built-in `default.templ` |
| Combinational Analysis > Build Circuit (FA0) | `AnalyzerModel` + `CircuitBuilder.build` |
| Placing components / attribute table / wires (including Logisim's automatic wire repair) | library component factories + `CircuitMutation` |
| Project > Add Circuit | `LogisimFile.addCircuit` |
| Project > Edit Circuit Appearance (custom block symbols, Labs 10–11) | `CircuitAppearance.setObjectsForce` with `Rectangle` / `Poly` / `Text` / `AppearancePort` |
| File > Save | `Loader.save` |

Then every file was checked three ways:

1. **Opened in the real Logisim GUI** (on a virtual X display). The only window is the main window, with no load-error dialog and no errors on stderr.
   See `gui-open-check.txt` and `gui_screenshot.png` in each lab folder.
2. **Simulated with Logisim's own simulator** (`CircuitState` / `Propagator`, the engine behind the Poke tool and Ctrl+T).
   The tests reload the saved file with a fresh `Loader` and fail if:
   - any output bit is unknown (blue `x`) or in error (red `E`)
   - any wire has a width mismatch (orange)
   - any result is wrong

   Results are in `test-results.txt` in each lab folder; all pass.
3. **Exported as pictures** using the same code as File > Export Image (the `images/` folders).

## Reproduce everything

```bash
build/run_all.sh        # downloads Logisim 2.7.1 + MARS 4.5, rebuilds, tests, runs MARS
# with DISPLAY set (e.g. `Xvfb :99 & export DISPLAY=:99`) it also opens every file in the Logisim GUI
```

You need Java 11 or newer. The GUI check also needs `xdotool` and `imagemagick`.
